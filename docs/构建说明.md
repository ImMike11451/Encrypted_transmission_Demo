# 构建说明

项目统一使用 CMake 和 C++17 构建。客户端与服务端分别生成 `encrypted-client`、`encrypted-server` 两个可执行文件。

## Linux 或 WSL 依赖

需要安装 CMake、C++17 编译器、OpenSSL、Protobuf、JsonCpp、MySQL 客户端开发库和线程库。

## 配置与构建

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel
```

只构建客户端：

```bash
cmake -S . -B build-client -DBUILD_SERVER=OFF
cmake --build build-client --parallel
```

如果 CMake 无法自动找到 MySQL 开发库，可显式传入路径：

```bash
cmake -S . -B build \\
  -DMYSQL_INCLUDE_DIR=/path/to/include \\
  -DMYSQL_LIBRARY=/path/to/libmysqlclient.so
```

构建只验证编译和链接，不会读取真实数据库密码，也不会连接数据库。

## Windows 说明

原有 Visual Studio Linux 工程仍可继续使用。后续 Qt 前端将作为独立 CMake 目标接入，不与当前命令行客户端混合。
