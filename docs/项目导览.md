## 项目简介

项目由一个服务端和两个命令行客户端组成。客户端分别与服务端协商会话密钥，发送方使用 AES-GCM 加密文本；服务端验证密钥状态后解密，再使用接收方会话密钥重新加密，完成存储和审计。

## 主要功能

- 密钥协商、校验和注销。
- 密钥有效期检查，以及再次协商时的密钥轮换。
- 文本加密发送、服务端重加密和数据库存储。
- 按消息 ID 查询元数据，以及查询最近发送记录。
- 记录消息发送、查询和失败操作的审计日志。

## 技术栈

| 技术 | 对应模块 | 用途 |
| --- | --- | --- |
| C++17 / CMake | 顶层与子目录 `CMakeLists.txt` | 构建客户端、服务端和测试 |
| TCP、epoll、线程池 | `TcpSocket`、`EpollServer`、`ThreadPool` | 网络连接和请求处理 |
| OpenSSL | `RsaCrypto`、`AesGcmCrypto` | RSA 密钥操作和 AES-GCM 消息加密 |
| Protobuf | `MessageV2.proto`、V2 编解码器 | 统一请求和响应格式 |
| MySQL | `mysqlOP`、`MessageRepository`、`AuditService` | 密钥、消息和审计持久化 |
| System V 共享内存 | `SecKeyShm` | 缓存活跃会话密钥 |
| CTest | `tests/` | 加密、编解码和查询规则测试 |

## 源码阅读顺序

1. [协议定义](../ServerSeckey/ServerSeckey/MessageV2.proto)：请求、响应和业务字段。
2. [ClientOP](../ClientSecKey/ClientSecKey/ClientOP.h) 与 [MessageClient](../ClientSecKey/ClientSecKey/MessageClient.h)：客户端菜单、密钥操作和消息发送。
3. [ServerOP](../ServerSeckey/ServerSeckey/ServerOP.h)：网络服务启动、任务分发和协议路由。
4. [MessageService](../ServerSeckey/ServerSeckey/MessageService.h)：消息解密、重加密与存储。
5. [MessageQueryService](../ServerSeckey/ServerSeckey/MessageQueryService.h)：单条和列表查询的归属校验。
6. [mysqlOP](../ServerSeckey/ServerSeckey/mysqlOP.h)：数据库操作与密钥生命周期。
